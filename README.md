# 🚀 AI Productivity Toolkit – Prompt Engineering

A beginner-friendly Prompt Engineering & AI Productivity Toolkit developed as part of an internship project.

This project demonstrates how well-designed prompts can be used for summarization, classification, content generation, structured outputs, coding assistance, and other AI productivity tasks.

## 📌 Project Overview

The AI Productivity Toolkit demonstrates practical prompt engineering techniques and reusable prompt templates.

The project focuses on creating clear prompts using:

- Roles
- Context
- Instructions
- Constraints
- Examples
- Output formats

## 🎯 Objectives

- Understand zero-shot and few-shot prompting.
- Create role-based prompts.
- Design prompts using context, instructions, and constraints.
- Generate structured JSON outputs.
- Create prompts for summarization and classification.
- Generate content using reusable templates.
- Design AI-assisted coding and debugging prompts.
- Evaluate prompts using a simple scoring system.

## 🧠 Features

### 1. Zero-Shot Prompting

Classifies text without providing examples.

### 2. Few-Shot Prompting

Uses examples to guide the expected response.

### 3. Role-Based Prompting

Assigns a specific role to the AI to improve task-focused responses.

### 4. Summarization

Creates concise summaries from longer text.

### 5. Text Classification

Classifies customer feedback into Positive, Negative, or Neutral categories.

### 6. Structured JSON Output

Demonstrates how prompts can request structured JSON responses.

### 7. Content Generation

Creates professional content based on topic, audience, and constraints.

### 8. Coding & Debugging Assistant

Creates prompts that identify programming errors and suggest corrected code.

### 9. Reusable Prompt Templates

Provides Python functions that can be reused with different inputs.

### 10. Prompt Evaluation

Evaluates prompts based on clarity, specificity, instructions, constraints, output format, and reusability.

## 📊 Prompt Evaluation

The project includes a simple evaluation system using the following criteria:

- Clarity
- Specificity
- Instructions
- Constraints
- Output Format
- Reusability

Each criterion is scored from 1 to 5.
